Welcome

Your agent for Chinese social media content

It helps Medibank's international student team decide what to post, which trends to ride and which creators to work with, and checks every post for compliance before it goes out.

The end goal

Chinese students realise student insurance matters and choose their insurer themselves, instead of leaving it all to their education agent.

Content on Chinese platforms informs, never sells: no prices, comparisons, links or "DM me". The comparing happens off the platform.

Built on evidence

Every strategy choice points to a source in references/evidence.md. Published data is marked E-; where there is no data yet, the agent says so and marks a working assumption A- with a plan to test it.

    Why this agent, not a normal AI chat

    A normal AI can write posts. This one knows what Medibank cannot say in China, and its knowledge stays up to date.

    What mattersNormal AI chatThis agent
    ComplianceWrites "best price", "DM me" freelyEvery draft scanned against rules with rule IDs, per platform
    FactsMay invent prices, cover or follower countsOnly facts from the knowledge base; unknowns marked "to be confirmed"
    TrendsTraining data months oldSearches current trends with dated sources, scores the risk
    CreatorsGeneric adviceScoring rules, hard stops, a roster and a dashboard
    ConsistencyDifferent answer each timeSame rules and tools every time, tested automatically
    EvidenceStates opinions as factsEvery strategy names its source or says it is an assumption to test
    OutputText you still have to designFinished posts with image cards, and edited vertical videos, in Medibank colours
    MemoryStarts from zero every chatKnowledge base the team maintains and improves

    The knowledge base keeps improving

    Get started

    Install as a Claude Code plugin

    /plugin install medibank-cn-social --marketplace fatalitehu-arch/medibank-china-social-agent

    Or give Claude Code the GitHub link and ask it to install the plugin. Try: "What trends can we ride right now?"

    Claude Code (cloned copy)

    cd medibank-china-social-agent
claude

    Skills load from .claude/skills/.

    Codex

    cd medibank-china-social-agent
codex

    Skills load from .agents/skills/. Try: $medibank-cn-social

    Claude.ai Project (no code)

    Upload SKILL.md, skills/*/SKILL.md, references/ and assets/templates/ to a Project. Steps in README.md.

    Command line

    python -m social_agent welcome
python -m social_agent creators
python -m social_agent trendscore examples/trends_sample.csv
