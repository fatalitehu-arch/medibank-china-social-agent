# Glossary 术语表

## 小红书 operations (many terms also apply on other platforms)

| 中文 | English | Meaning |
|------|---------|---------|
| 笔记 | Note | A post (图文 = image + text; 视频 = video) |
| 博主 / 达人 | Creator | Anyone who publishes; 达人 is the 蒲公英 term |
| KOL | Key opinion leader | Creator with large reach (here: 10k+ followers) |
| KOC | Key opinion consumer | Small creator / real user (1k–10k) with high trust |
| 头部 / 腰部 / 尾部 | Top / mid / small tier | Follower tiers |
| 蒲公英 | Pugongying | 小红书's official brand-creator collaboration platform |
| 报备 | Reported collaboration | A paid note registered through 蒲公英; shows a sponsor tag |
| 水下 / 私单 | Under-the-table deal | Paid note not reported; penalised |
| 聚光 | Juguang | 小红书's paid ad platform |
| 企业号 / 专业号 | Brand account | Verified business account |
| 种草 | Seeding | Recommending something so people want it (for OSHC we "inform", not 种草 a purchase) |
| 铺量 | Volume seeding | Many notes at once; risky if scripts are identical |
| 限流 | Throttling | Platform limits a note's distribution |
| 导流 / 引流 | Diversion | Sending users off-platform (WeChat, links) |
| 收藏 | Save | Strong "useful" signal |
| 合集 / 专辑 | Collection | A series grouped together |
| 舆情 | Public sentiment / crisis | Negative attention that may spread |
| 封面文案 | Cover text | Big text on the first image |

| 微信公众号 / 服务号 / 订阅号 | WeChat Official Account (Service / Subscription) | Overseas entities can register only a Service Account |
| 视频号 | WeChat Channels | Short video inside WeChat |
| 互选平台 | WeChat Mutual Selection platform | Official marketplace for paid 公众号 / 视频号 creator placements |
| 抖音 / 巨量星图 | Douyin / Xingtu | Short-video platform / its official creator marketplace |
| 巨量引擎 | Ocean Engine | Douyin's ad platform |
| 微博 / 蓝V / 微任务 | Weibo / verified brand account / commercial order system | |
| 话题 / 热搜 | Topic / trending list | Weibo topics (#话题#) and hot searches |
| 诱导分享 | Induced sharing | "转发领资料" mechanics; penalised on WeChat |
| 家长群 | Parents' group chat | Where 视频号 and 公众号 content spreads |

## Insurance and study

| 中文 | English | Meaning |
|------|---------|---------|
| 海外学生健康保险 | OSHC, Overseas Student Health Cover | Health cover required for Student visa (subclass 500) holders |
| 学生签证（500） | Student visa subclass 500 | Australian student visa |
| 录取通知书 / offer letter | Letter of Offer | University offer; usually shows OSHC arrangements and fees |
| CoE | Confirmation of Enrolment | Issued after acceptance; needed for the visa |
| GP / 全科医生 | General practitioner | First stop for non-emergency care |
| 急诊 | Emergency department | Hospital emergency; call 000 for emergencies |
| 自付差额 / gap | Gap fee | What you pay above the insurer's benefit |
| 等待期 | Waiting period | Time before certain benefits apply |
| MBS | Medicare Benefits Schedule | Government fee schedule OSHC benefits are based on |
| 留学中介 | Education agent | Helps with applications and visas; often arranges OSHC |
| 内政部 | Department of Home Affairs | Australian visa authority |
