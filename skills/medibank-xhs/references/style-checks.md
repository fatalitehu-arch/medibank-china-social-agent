# Style checks (run after the body is written)

> Adapted from `checks.md` and `cover-title.md` in
> [aislinn-yang/rednote-writing-skill](https://github.com/aislinn-yang/rednote-writing-skill)
> (MIT License, © 2026 Aislinn Yang), with Medibank- and insurance-specific additions.
> Compliance rules (the 🔴/🟡 list) live in `compliance.md`; this file is about style
> and platform reach.

Scan the body, the titles and the cover lines. Titles get the strictest check.

## 1. Punctuation

* Half-width commas and full stops inside Chinese sentences → full-width (，。)
* Long dashes「——」→ comma, full stop or brackets
* Avoid stacking punctuation (！！！, ？？？)

## 2. AI-flavour phrases (rewrite into plain speech)

| Phrase | Replace with |
|--------|--------------|
| 说白了 / 本质上 | 其实就是 / 说到底 |
| 这意味着 | 所以呢 / 结果就是 |
| 值得注意的是 / 不难发现 | delete, say it directly |
| 综上所述 / 总的来说 | a concrete closing line |
| 首先…其次…最后 | natural transitions, or numbered steps |
| 在当今…的时代 / 随着…的发展 | start from a real scene |
| 希望对你有帮助 | a real question for the comments |

## 3. Structural AI-flavour

* Markdown headings or bold sub-headings inside a note → use emoji markers or numbers
* More than 3 bullet opinions in a row → turn into sentences
* Made-up example stories ("比如有个同学…") → only real, consented stories, or say
  "很多同学会遇到…"

## 4. Absolute terms (广告法 Art. 9(3); also CN-7)

最 / 最佳 / 最好 / 最大 / 最便宜 / 第一 / 唯一 / 首选 / 独家 / NO.1 / 顶级 / 极致 /
权威 / 绝对 / 100% / 百分百 / 保证 / 一定 / 永久 / 彻底

## 5. Reach killers on 小红书

* Diversion: 微信 / vx / V信 / 加V / 私我 / 私信我 / 扫码 / 二维码 / 公众号 / QQ / 电话
* Money promises: 稳赚 / 包过 / 零风险 / 躺赚
* Marketing jargon: 引流 / 私域 / 割韭菜 / 刷量

## 6. Titles

* 3–5 options, ≤ 20 Chinese characters, core keyword in the first 10
* Styles: question / number / scene / contrast. No 标题党 (clickbait)
* No emoji, no stacked exclamation marks, no absolute terms
* Banned filler: 干货 / 必看 / 超实用 / 一定要收藏

## 7. Cover lines

* 2–3 options, readable in one glance (≤ 12 characters per line)
* Different from the title; speak to the exact reader ("刚拿到 offer 的你")

## Pass standard

Zero hits in sections 4 and 5. Sections 1–3: fix unless fixing makes the sentence
stiff; then leave it.
