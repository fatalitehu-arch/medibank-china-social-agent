How to use the Medibank Social Agent

An AI agent for Medibank's Chinese social media (小红书, 公众号, 视频号, 抖音, 微博): it finds creators, writes posts, cuts short videos, plans content and checks every draft for compliance. Four things to know:

1What it can do 2Use it in this browser 3Better ways to use it 4Change it and move it to Medibank

1What it can do

Nine skills, one rule: on Chinese platforms Medibank informs and helps, it never sells.

Find creatorsA tested Xiaohongshu search method and a library of 28 scouted creators, scored and sorted
Write postsFinished text, titles, hashtags and image cards in Medibank colours
Edit short videosVertical cuts with subtitles, colour tone, title and end cards
Compliance check🟢 🟡 🔴 verdict against PRC, Australian and platform rules, with fixes
Plan contentMonthly and intake calendars across five platforms
Ride trendsWhat is hot this week and whether Medibank can safely use it
Replies and 舆情Comment and DM replies, weekly listening, crisis levels
RepurposeOne approved post turned into native versions for the other platforms
Performance reportsExported platform data turned into a monthly report with next steps

2Use it in this browser

Keep the small black window (Terminal or Command Prompt) open while you use this page. Closing it stops the agent.

With an Anthropic API key: the full agent

  1. Get a key at console.anthropic.com (Settings, API keys). Usage is billed to that account.
  2. Click No API key at the top right, paste the key and press Connect. Tick “Remember” to keep it on this computer only.
  3. Open Agent and pick a suggestion or ask in Chinese or English, for example “写一篇小红书笔记：第一次在悉尼看 GP”.

If it does not open next time

Mac: “Not Opened” / “Apple could not verify”Click Done (not Move to Bin). Open System Settings → Privacy & Security, scroll down, click Open Anyway, enter your password, click Open Anyway again.
Windows: “Windows protected your PC”Click More info, then Run anyway.
Windows: “Open File – Security Warning”Click Run. To skip these boxes next time: before unzipping, right-click the zip → Properties → tick Unblock → OK.
“Python 3.10 or newer is needed”Install Python from python.org/downloads (the yellow button), then double-click the start file again.
“Already running”The agent is open already; the browser shows it. Close the extra window.
An old version of this page opensThe new copy starts on port 8788 by itself; the black window shows the address. To stop the old one, close all its black windows.

3Better ways to use it

This web page is the simple version. The same agent runs in these tools, which can do more (longer tasks, your own files, browser search on Xiaohongshu).

Claude Code Recommended

Uses a Claude subscription, no separate API key. Open the Code tab in the Claude desktop app (or run claude in a terminal) and paste:

claude plugin marketplace add fatalitehu-arch/medibank-china-social-agent
claude plugin install medibank-cn-social@medibank-china-social

Then just ask, for example “怎么找博主？”. The nine skills load on their own.

Claude.ai Project No code

  1. In Claude.ai create a Project, for example “Medibank 中国社媒”.
  2. Upload SKILL.md, every skills/*/SKILL.md, the references/ folder and assets/templates/ from this folder.
  3. Project instructions: “Follow SKILL.md. Never write prices, links, QR codes or purchase calls to action.”

It cannot run the Python tools, so run the compliance scan here (Demo) on anything high-reach.

OpenAI Codex

Run codex in this folder. Skills load from .agents/skills/ and AGENTS.md gives the rules.

Command line

For scripts and automation: python -m social_agent write "…" --platform xiaohongshu, check, plan, chat. Offline (no key): scan, creators, kol, calendar, report.

4Change it and move it to Medibank

Everything (skills, knowledge base, rules, creator library and this web app) is plain files in one GitHub repository. The folder you are running is a copy of it.

github.com/fatalitehu-arch/medibank-china-social-agent

What to edit where

Skills (what the agent does)SKILL.md, skills/cn-*/SKILL.md
Knowledge basereferences/ (compliance, brand facts, evidence, platforms)
Compliance scanner rulestools/rules.json
Brand coloursassets/brand/theme.json
Creator librarycreators/scouted/xiaohongshu.csv
Templates (briefs, replies, reports)assets/templates/
This web appsocial_agent/web.py, social_agent/web_page.html

After editing, run python sync_skills.py, python tools/build_welcome.py, python tools/build_portfolio.py and python -m pytest -q tests. Or ask Claude Code to make the change and run these for you.

Move it to Medibank's own GitHub (data privacy)

The current repository belongs to the student team and is public. Before adding real creator contacts, campaign results or drafts, move it to a private repository Medibank controls.

  1. In Medibank's GitHub organisation, create a new private repository.
  2. Copy everything into it with GitHub's Import repository page (github.com/new/import, paste the address above), or:
git clone --mirror https://github.com/fatalitehu-arch/medibank-china-social-agent.git
cd medibank-china-social-agent.git
git push --mirror https://github.com/MEDIBANK-ORG/NEW-REPO.git
  1. Replace fatalitehu-arch/medibank-china-social-agent with the new address in README.md and .claude-plugin/, then install from the new repository.
  2. Give access only to the social and legal team. Never commit API keys: they stay on each computer.
