Medibank Social Agent

Searches the real scouted creator library (Xiaohongshu, view only). No API key needed.

Paste a draft post. The keyword scanner checks it against the PRC, Australian and platform rules. No API key needed.

Renders a finished sample post (examples/post_spec.json) as image cards in Medibank colours, with its compliance check. With an API key, the agent writes new posts the same way.

Runs on this computer. Files it makes are saved in outputs/web/ inside the agent folder. Every reply is keyword-scanned for compliance; a person still approves before anything is posted.
